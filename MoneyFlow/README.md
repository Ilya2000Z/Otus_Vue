# MoneyFlow

Продвинутый финансовый трекер доходов, расходов и планирования бюджета — SPA на Vue 3 с данными в LocalStorage и поддержкой PWA.

## Стек

Vue 3 (Composition API), Pinia, Vue Router, Vuetify 3, TypeScript, Vite, PWA (vite-plugin-pwa).

## Функционал

- Учёт доходов и расходов
- CRUD транзакций
- Категории операций (доходы/расходы)
- Планирование бюджета по категориям
- Дашборд со статистикой (доход, расход, баланс)
- Фильтрация по периоду (месяц)
- Детальная страница и редактирование операции
- Отображение перерасхода бюджета
- Тёмная тема
- Адаптивный интерфейс
- Валидация форм
- **Модуль «Путешествия»** (Развлечения → Путешествия): город отправления/прибытия, бюджет, тип поездки (общественный транспорт / авто). Расчёт маршрута, транспортных расходов, бюджета на перекусы (10%), точки остановок (кафе), активности в городе назначения. Данные через сервисный слой с mock fallback; последний план кэшируется для offline.
- PWA: установка как приложение, offline, кэш статики.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

E2E-тесты:

```bash
npm run test:e2e
```

## Практики Vue 3

- Composition API, `<script setup>`
- Pinia stores с getters
- Provide/Inject для общего периода фильтра
- Async-компоненты и слоты (AppCard, StatCard)
- Плагин форматирования валюты
- Композиционные функции (useCurrency, usePeriodFilter)
